Part One — Windows Installation

Before You Begin

RetailPro runs inside Docker containers, so Windows itself only needs one thing installed: Docker Desktop. Everything else — Node.js, MySQL, Nginx — lives inside the containers and never touches your system directly.

You'll need
  • Windows 10/11 (64-bit)
  • Docker Desktop for Windows
  • WSL2 enabled (Docker Desktop sets this up for you)
  • 2GB+ free RAM, ports 5175, 5002, 3306 free
You will run everything from

PowerShell — not Command Prompt. Right-click the Start menu and choose Windows PowerShell (or Terminal on Windows 11).

Install Docker Desktop

  1. Download and install

    Get Docker Desktop from docker.com/products/docker-desktop and run the installer. Accept the default option to use WSL2.

  2. Restart if prompted

    The installer may ask to restart Windows to finish enabling WSL2. Do this before continuing.

  3. Start Docker Desktop and wait for it to say "Running"

    Look for the whale icon in your system tray (bottom-right, near the clock). It needs to be solid/steady before you run any docker command — if PowerShell says "error during connect", Docker Desktop just isn't finished starting yet.

  4. Verify it works

    docker --version
docker compose version

    Both should print a version number. If either fails, Docker Desktop isn't running — open it from the Start menu first.

Extract the Project

You'll have received RetailPro as a .zip file. Windows does not have a built-in unzip command in PowerShell — trying to run unzip directly will fail. Use one of these instead:

Option A — PowerShell 
cd C:\Users\<you>\Desktop
Expand-Archive -Path RetailPro-5.0.zip -DestinationPath .
cd retailpro
Option B — File Explorer

Right-click the zip → Extract All… → choose your Desktop → open the extracted retailpro folder.

Confirm you're in the right folder before continuing — you should be inside the folder that directly contains docker-compose.yml: 
dir docker-compose.yml
If that lists the file, you're in the correct place.

Launch the Stack

  1. Build and start all three containers

    docker compose up -d --build

    This downloads base images, installs dependencies, and builds the frontend and backend. On a fresh machine this can take several minutes — that's normal. You'll see build steps for mysql, backend, and frontend scroll past.

  2. Wait for MySQL to report healthy

    docker compose ps

    You want all three containers — retailpro_mysql, retailpro_backend, retailpro_frontend — showing Up, with MySQL specifically showing healthy. This can take 20–30 seconds after the build finishes.

  3. Open the app

    http://localhost:5175

    Since nothing is installed yet, you'll land straight on the Installation Wizard.

Installation Wizard — Step by Step

    Click Get Started.

  2. Database Connection

    The defaults already match the bundled Docker MySQL container — just click Test Connection.

Day-to-Day Commands

Once installed, this is the entire command set you'll need for ongoing use, all from inside the retailpro folder:

TaskCommand
Start the storedocker compose up -d
Stop the store (keeps all data)docker compose down
Check what's runningdocker compose ps
View backend logsdocker compose logs -f backend
Rebuild after a code updatedocker compose up -d --build
Full reset — wipes all datadocker compose down -v

Your database and install state live in named Docker volumes, so stopping and restarting (down then up -d) never asks you to reinstall. Only down -v erases data.

Common Windows Issues

These are the exact issues most people hit on a first Windows install, in the order you're likely to hit them.

Issue

"'unzip' is not recognized as an internal or external command"

Windows PowerShell has no built-in unzip. Fix: use Expand-Archive -Path RetailPro-5.0.zip -DestinationPath . instead, or extract via File Explorer's "Extract All."

Issue

"no configuration file provided: not found"

This means docker compose was run from the wrong folder — usually because a previous cd command failed silently and you never actually moved into the retailpro directory. Fix: run dir docker-compose.yml to confirm you're in the right place before running compose commands.

Harmless

"the attribute `version` is obsolete, it will be ignored…"

Just a warning, not an error — newer Docker Compose auto-detects the file format and no longer needs a version: line. Safe to ignore, or delete that line from docker-compose.yml to silence it permanently.

Issue

"ports are not available: exposing port TCP 0.0.0.0:3306 … bind: Only one usage of each socket address…"

Something already on your Windows machine is using port 3306 — commonly a local MySQL install, XAMPP, or MySQL Workbench's bundled server. This only affects the host-side port mapping, not RetailPro itself, since the backend talks to MySQL over the internal Docker network regardless. Fix: in docker-compose.yml, change the mysql service's port mapping from "3306:3306" to "3307:3306" (or any free port), save, then run docker compose up -d again — no rebuild needed.

Issue

Querying a table gives "Table 'retailpro.Users' doesn't exist"

MySQL table names created by RetailPro are lowercase (e.g. users, products, accounts) even though the model names in code are capitalized. Fix: always query with lowercase table names — SELECT * FROM users; not FROM Users;. Run SHOW TABLES; if you're ever unsure of the exact name.

Issue

Login page says "Invalid email or password" but you're sure it's right

Almost always a typo mismatch between what you think you typed during install and what actually got saved — commonly guessing a generic email like admin@yourcompany.com instead of the real one entered. Fix: confirm the real saved email first:

docker compose exec mysql mysql -uretailpro -pretailpro retailpro -e "SELECT name, email, role FROM users;"
Issue

Wizard says "Table 'retailpro.accounts' doesn't exist" during Review & Install

This can happen if an earlier install attempt was interrupted or the database volume was reset separately from the app's install flag. Fix: just go back to http://localhost:5175/install and run the wizard again — the Database step will reconnect and Review & Install will recreate every table cleanly. If the wizard redirects you straight to /login instead of showing the form, clear the stuck install flag first:

docker compose exec backend rm -f /app/data/.installed
docker compose restart backend
Recovery

Lost or forgotten admin password

There's no self-service reset yet. Reset it directly:

docker compose exec backend node -e "console.log(require('bcryptjs').hashSync('NewPass123!', 10))"

Copy the printed hash, then:

docker compose exec mysql mysql -uretailpro -pretailpro retailpro -e "UPDATE users SET password_hash='<PASTE_HASH>' WHERE email='you@example.com';"
General rule of thumb: whenever a command's output looks wrong or an error mentions something unexpected, run docker compose ps first. Nine times out of ten the real cause is one container not actually running yet, or not being healthy — everything downstream fails until MySQL finishes starting up.
Part Two — User Manual

Signing In & Roles

Sign in with the email and password created during installation, or one issued to you by your administrator. The sidebar and available actions adapt automatically to your role.

RoleCan do
CashierPoint of Sale, view Sales History
ManagerEverything a Cashier can, plus Products, Categories, Inventory, Purchasing, Suppliers, Customers
AccountantNominal Ledger (Chart of Accounts, Journal, reports), plus read access elsewhere
AdminEverything, including Users and Settings

Point of Sale

This is the checkout screen your cashiers will live in all day.

Scanning items

Click into the scan bar (auto-focused on open). Any standard USB/Bluetooth barcode scanner types like a keyboard — scanning a barcode types the code and presses Enter automatically, adding the matching product straight to the cart. No drivers needed.

Adding items manually

Use the search box to filter by name or SKU, or click a product tile directly in the grid.

The cart

Every item you add appears on the receipt-style panel on the right, showing quantity, unit price, and line total. Use − / + to change quantity, or remove to delete a line.

Completing a sale

Choose a payment method (see Payment Options below), enter amount received for cash sales, then click Charge. Stock is deducted instantly and the accounting entries — revenue, tax, and cost of goods sold — post automatically. A printable receipt opens right after checkout; see Thermal Receipt Printing.

Payment Options

RetailPro supports five payment methods at checkout, on both the sales and purchasing sides:

Cash
Card
Mobile Money
Bank Transfer
On Credit
MethodBehavior
CashEnter amount received — RetailPro calculates change due automatically.
Card / Mobile Money / Bank TransferRecorded as paid in full at the time of sale; posts to your Bank account in the ledger.
On CreditRequires selecting a customer (sales) or supplier (purchases). The amount is added to their balance instead of being settled immediately, and posts to Accounts Receivable / Payable.

Thermal Receipt Printing

Every completed sale automatically opens a print-formatted receipt sized for 80mm thermal paper, using your printer's normal Windows driver through the browser's print dialog — the same way any thermal receipt printer (Epson TM-series, Star, generic USB/Bluetooth models) is meant to be used.

  1. Install your printer

    Plug in or pair your thermal printer and install its Windows driver as usual — this comes from the printer manufacturer, not RetailPro.

  2. Set it as default (optional)

    In Windows Settings → Printers & scanners, set the thermal printer as default so the print dialog pre-selects it automatically.

  3. Print

    Complete a sale — the receipt opens and the print dialog appears automatically. Confirm the correct printer is selected and print.

You can also reprint any past invoice from Sales History → View → Print Receipt.

Sales History

Every completed sale is listed with invoice number, date, customer, payment method, and total. Click View for the full line-item breakdown of any invoice, or Print Receipt to reprint it.

Add and manage everything you sell.

Inventory

Stock levels

Every active product with a badge showing In Stock or Reorder Soon.

Adjust

Manually add or remove stock for counts, damage, theft, or corrections — with a required note for your audit trail.

History

Full movement log per product: every sale, purchase receipt, and manual adjustment, in order.

Toggle to show only items at or below their reorder level.

Purchasing

  1. Create the order

    Click New Purchase Order, choose a supplier and payment method, and add line items (product, quantity, unit cost, tax rate). The order is created as Ordered — stock is not affected yet.

  2. Receive goods

    When goods physically arrive, click Receive Goods. This is the moment stock increases, product cost prices update to the latest purchase cost, and accounting entries post automatically — inventory asset, tax, and either cash/bank or accounts payable.

Suppliers & Customers

Basic contact records with a running balance: Suppliers show what you owe them from credit purchases (accounts payable); Customers show what they owe you from credit sales (accounts receivable).

Nominal Accounting

RetailPro keeps a full double-entry set of books behind every sale and purchase, so your accounts stay current without manual bookkeeping.

Chart of Accounts

Asset, liability, equity, income and expense accounts — a standard set is seeded at install, and you can add your own.

Journal

Every transaction, automatic or manual, as balanced debit/credit lines. Use Manual Journal Entry for things RetailPro doesn't post automatically.

Trial Balance

Total debits and credits per account — they must match.

Profit & Loss / Balance Sheet

Income minus expenses for the period, and a live check confirming Assets = Liabilities + Equity.

Users

Administrators can create logins for staff and assign a role, or disable access for anyone who leaves — without deleting their sales history.

Settings & Currency

Update your company name, address, contact details, currency, default tax rate, and receipt footer at any time — changes apply immediately across the app.

RetailPro is currency-agnostic: whichever currency you chose at install (or later in Settings) is used for every price, invoice, and report. There's no per-transaction conversion — RetailPro assumes your business operates in a single base currency.

Tips for a Smooth First Day

  • Add your Categories first, then your Products — it keeps the POS grid organized.
  • Enter accurate Cost Prices on every product — this drives your automatic Cost of Goods Sold and profit reporting.
  • Set sensible Reorder Levels so the Inventory page actually warns you before you run out.
  • Use On Credit payments sparingly and follow up via the Customers/Suppliers balance columns.
  • Keep your admin password somewhere durable — a password manager beats a sticky note, but a sticky note beats losing access entirely.
