Part One — Installation

Overview

RetailPro ships as three containers — a React/Vite storefront, a Node.js/Express API, and MySQL — orchestrated with a single Docker Compose file. There's no manual database setup: a guided Installation Wizard handles your schema, chart of accounts, currency, and admin account the first time you open the app.

🛒

POS with Barcode Scanning

Any USB or Bluetooth scanner works out of the box — it types like a keyboard, RetailPro does the rest.

📥

Purchasing

Raise purchase orders, receive goods, and watch stock and cost prices update automatically.

📊

Inventory

Live stock levels, reorder alerts, manual adjustments, and a full movement audit trail.

📒

Nominal Accounting

Real double-entry bookkeeping — every sale and purchase posts itself to the ledger.

Requirements

For Docker installation (recommended)
  • Docker Engine 24+ and Docker Compose v2
  • Ports 5175, 5002, 3306 free
  • 2GB free RAM minimum
For manual installation
  • Node.js 20+
  • MySQL 8.0+ running locally
  • A database and user created in advance

Docker Installation

This is the fastest path to a working store and the one most people should use.

  1. Get the project files

    Unzip the RetailPro folder onto your machine or server, then move into it.

    cd retailpro

  2. Build and start the stack

    This single command builds and starts all three containers — MySQL, the API, and the storefront.

    docker compose up -d --build

    Give MySQL 20–30 seconds on first boot to finish initializing. The backend waits on a health check automatically, so you don't need to time this yourself.

  3. Open the app

    Visit the frontend in your browser. Since nothing is installed yet, you'll be redirected straight into the Installation Wizard.

    http://localhost:5175

  4. Complete the wizard

    Follow the six steps covered in Installation Wizard below — database, company & currency, admin account, review, install.

  5. (Optional) Load demo data

    See Loading Demo Data to populate the store with realistic products, customers, and sales history.

Managing the stack — a few commands you'll use often: 
docker compose ps                 # see running containers
docker compose logs -f backend    # tail backend logs
docker compose down               # stop everything (data is preserved)
docker compose down -v            # stop AND wipe all data — use with care
Your database and the installer's saved configuration live in named Docker volumes, so stopping and restarting the stack will not ask you to reinstall.

Manual Installation Development

Useful for local development without Docker. You'll run the frontend and backend as two separate Node processes against a MySQL server already running on your machine.

  1. Create the database

    Connect to your local MySQL server and run:

    CREATE DATABASE retailpro;
CREATE USER 'retailpro'@'localhost' IDENTIFIED BY 'retailpro';
GRANT ALL PRIVILEGES ON retailpro.* TO 'retailpro'@'localhost';

  2. Start the backend

    cd backend
npm install
npm run dev

    The API starts on http://localhost:5002 and reports itself as "not installed" until the wizard runs.

  3. Start the frontend

    In a second terminal:

    cd frontend
npm install
npm run dev

    Opens on http://localhost:5175 and proxies API calls to the backend automatically.

  4. Run the wizard

    Same steps as Docker — just use host: localhost instead of host: mysql on the database step.

Installation Wizard — Step by Step

The wizard runs once, the first time RetailPro starts with an empty database. Here's exactly what each screen asks for.

  1. Welcome

    A quick overview of what's about to happen and what you'll need. Click Get Started.

  2. Database Connection

    Host, port, database name, username, and password. If you're using the bundled Docker Compose stack, the pre-filled defaults already match the bundled MySQL container — just click Test Connection.

    FieldDocker default
    Hostmysql
    Port3306
    Databaseretailpro
    Usernameretailpro
    Passwordretailpro

  3. Company & Currency

    Your company name, phone, email, and address — these appear on printed receipts. Then choose your currency from 15 built-in options (USD, EUR, GBP, NGN, GHS, KES, ZAR, INR, AED, CAD, AUD, JPY, CNY, BRL, EGP) and set your default sales tax rate. This currency is used everywhere — POS, invoices, reports — and can be changed later in Settings.

  4. Admin Account

    The first login for your store — full access to every module, including user management and accounting. Write this password down somewhere safe before continuing; there's no self-service password reset yet.

  5. Review & Install

    A final summary of everything above. Clicking Install RetailPro 5.0 creates every database table, seeds a standard chart of accounts, saves your settings, and creates your admin user.

  6. Done

    Click Go to Login and sign in with the admin account you just created.

Loading Demo Data

To explore RetailPro with a populated store instead of a blank install, run the seed script from a terminal:

docker compose exec backend npm run seed

This generates:

  • 10 categories and 50 products — with barcodes ready to scan
  • 5 suppliers and 12 customers
  • 8 historical purchase orders (6 received into stock, 2 still pending)
  • Roughly 100–150 historical sales spread across the last 22 days, so the Dashboard, Accounting reports, and Inventory levels all look like an active store

It also creates three extra staff logins so you can see how each role's access differs:

RoleEmailPassword
Managermanager@retailpro.demoDemo1234!
Cashiercashier@retailpro.demoDemo1234!
Accountantaccountant@retailpro.demoDemo1234!

The script is safe to re-run — it won't duplicate products, suppliers, or customers, and skips regenerating sales history if some already exists.

Troubleshooting

SymptomFix
"Test Connection" fails in the wizardConfirm MySQL is running and reachable. In Docker, the host must be mysql (the service name), not localhost.
Port already in useSomething else is using 5175, 5002, or 3306. Stop it, or change the host-side port mapping in docker-compose.yml (the container-side port can stay the same).
Stuck redirecting to /install after installingClear local storage for the site and refresh, or check docker compose logs backend for errors during install.
Forgot the admin passwordQuery SELECT email FROM users; via docker compose exec mysql mysql ... to confirm the email, then reset the hash directly — see the note below.
Need to start over completelydocker compose down -v wipes the database and install state, then docker compose up -d --build to reinstall from scratch.
Resetting a lost password — there's no self-service reset flow yet. From a terminal: 
docker compose exec backend node -e "console.log(require('bcryptjs').hashSync('NewPass123!', 10))"
docker compose exec mysql mysql -uretailpro -pretailpro retailpro \
  -e "UPDATE users SET password_hash='<PASTE_HASH>' WHERE email='you@example.com';"
Part Two — User Manual

Signing In & Roles

Sign in with the email and password created during installation, or one issued to you by your administrator. The sidebar and available actions adapt automatically to your role.

RoleCan do
CashierPoint of Sale, view Sales History
ManagerEverything a Cashier can, plus Products, Categories, Inventory, Purchasing, Suppliers, Customers
AccountantNominal Ledger (Chart of Accounts, Journal, reports), plus read access elsewhere
AdminEverything, including Users and Settings

Point of Sale

This is the checkout screen your cashiers will live in all day.

Scanning items

Click into the scan bar (auto-focused on open). Every standard USB/Bluetooth barcode scanner types like a keyboard — scanning a barcode types the code and presses Enter automatically, adding the matching product straight to the cart. No drivers needed.

Adding items manually

Use the search box to filter by name or SKU, or click a product tile directly in the grid.

The cart

Every item you add appears on the receipt-style panel on the right, showing quantity, unit price, and line total. Use − / + to change quantity, or remove to delete a line.

Completing a sale

Choose a payment method (see Payment Options below), enter amount received for cash sales, then click Charge. Stock is deducted instantly and the accounting entries — revenue, tax, and cost of goods sold — post automatically. A printable receipt opens right after checkout; see Thermal Receipt Printing.

Payment Options

RetailPro supports five payment methods at checkout, on both the sales and purchasing sides:

Cash
Card
Mobile Money
Bank Transfer
On Credit
MethodBehavior
CashEnter amount received — RetailPro calculates change due automatically.
Card / Mobile Money / Bank TransferRecorded as paid in full at the time of sale; posts to your Bank account in the ledger.
On CreditRequires selecting a customer (sales) or supplier (purchases). The amount is added to their balance instead of being settled immediately, and posts to Accounts Receivable / Payable.

Thermal Receipt Printing

Every completed sale automatically opens a print-formatted receipt sized for 80mm thermal paper. This uses your printer's normal Windows/Mac driver through the browser's print dialog — the same way any thermal receipt printer (Epson TM-series, Star, generic USB/Bluetooth models) is meant to be used.

  1. Install your printer

    Plug in or pair your thermal printer and install its driver as usual — this comes from the printer manufacturer, not RetailPro.

  2. Set it as default (optional)

    In your OS printer settings, set the thermal printer as default so the print dialog pre-selects it automatically.

  3. Print

    Complete a sale — the receipt opens and the print dialog appears automatically. Confirm the correct printer is selected and print.

You can also reprint any past invoice from Sales History → View → Print Receipt.

Sales History

Every completed sale is listed with invoice number, date, customer, payment method, and total. Click View for the full line-item breakdown of any invoice, or Print Receipt to reprint it.

Products & Categories

Add and manage everything you sell.

FieldPurpose

Tax RateApplied per item at checkout

Deactivating a product hides it from POS without deleting its sales history. Categories are simple groupings (e.g. Beverages, Snacks, Household) used to organize and filter products.

Inventory

Stock levels

Every active product with a badge showing In Stock or Reorder Soon.

Adjust

Manually add or remove stock for counts, damage, theft, or corrections — with a required note for your audit trail.

History

Full movement log per product: every sale, purchase receipt, and manual adjustment, in order.

Low stock filter

Toggle to show only items at or below their reorder level.

Purchasing

  1. Create the order

    Click New Purchase Order, choose a supplier and payment method, and add line items (product, quantity, unit cost, tax rate). The order is created as Ordered — stock is not affected yet.

  2. Receive goods

    When goods physically arrive, click Receive Goods. This is the moment stock increases, product cost prices update to the latest purchase cost, and accounting entries post automatically — inventory asset, tax, and either cash/bank or accounts payable.

Suppliers & Customers

Basic contact records with a running balance: Suppliers show what you owe them from credit purchases (accounts payable); Customers show what they owe you from credit sales (accounts receivable).

Nominal Accounting

RetailPro keeps a full double-entry set of books behind every sale and purchase, so your accounts stay current without manual bookkeeping.

Chart of Accounts

Asset, liability, equity, income and expense accounts — a standard set is seeded at install, and you can add your own.

Journal

Every transaction, automatic or manual, as balanced debit/credit lines. Use Manual Journal Entry for things RetailPro doesn't post automatically.

Trial Balance

Total debits and credits per account — they must match.

Profit & Loss / Balance Sheet

Income minus expenses for the period, and a live check confirming Assets = Liabilities + Equity.

Users

Administrators can create logins for staff and assign a role, or disable access for anyone who leaves — without deleting their sales history.

Settings & Currency

Update your company name, address, contact details, currency, default tax rate, and receipt footer at any time — changes apply immediately across the app.

RetailPro is currency-agnostic: whichever currency you chose at install (or later in Settings) is used for every price, invoice, and report. There's no per-transaction conversion — RetailPro assumes your business operates in a single base currency.

Tips for a Smooth First Day

  • Add your Categories first, then your Products — it keeps the POS grid organized.
  • Enter accurate Cost Prices on every product — this drives your automatic Cost of Goods Sold and profit reporting.
  • Set sensible Reorder Levels so the Inventory page actually warns you before you run out.
  • Use On Credit payments sparingly and follow up via the Customers/Suppliers balance columns.
